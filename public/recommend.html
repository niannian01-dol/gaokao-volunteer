分档口径

位次法（推荐）：gap =（该专业往年最低位次 − 你的位次）÷ max(你的位次, 500)

· −30% ≤ gap ≤ −8% → 冲：往年录取位次比你靠前 8%~30%

· −8% < gap ≤ 12% → 稳：与你的位次相当，作为主力志愿

· 12% < gap ≤ 45% → 保：你的位次明显优于往年录取位次

· 超出这个范围的不再列出：差太远冲不上，或过于保守浪费志愿名额。

分数法（缺一分一段表时兜底）：与往年最低分相比，低 0～20 分为冲，高 0～12 分为稳，高出 12～30 分为保。

阈值可在 public/assets/core.js 的 RANK_RULES / SCORE_RULES 里调整。

推荐结果基于往年录取数据统计，仅供参考，不构成录取承诺。
